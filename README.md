# Seatify frontend

React/Vite frontend for Seatify.

1. Copy `.env.example` to `.env`.
2. Set `VITE_API_URL` to the public URL of the Seatify API. For local development, use `http://localhost:5000`.
3. Run `npm install`.
4. Run `npm run dev`, or create a production build with `npm run build`.

Only variables prefixed with `VITE_` are sent to the browser. Never put passwords or private API keys in this file.
